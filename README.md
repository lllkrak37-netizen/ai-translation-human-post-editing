# AI Translation & Human Post-Editing 

## Project Objective
Analyzing AI systems outputs across various topics and assessing their suitability for Turkish localization.

## AI systems used 

TranslateGemma

## Source Language

English

## Target Language

Turkish

## Evaluation Criteria
 
-Meaning accuracy
-Fluency
-Terminology
-Contextual usage
-Style
-Grammar/QA


## Project Methodology 

1. Selected English language articles from different domains.
2. Generated AI translations
3. Reviewed AI outputs against the source text. 
4. Identified meaning, terminology, fluency and contextual issues.
5. Produced human post-edited versions.
6. Evaluated translation quality.
7. Documented representative post-editing decisions.


## Main Findings 
-Gemma has translated the given texts with a robotic view and it did not sound natural.
-Translations mostly were too direct.
-Majority of the idiomatical expressions and phrases were translated out of context.
